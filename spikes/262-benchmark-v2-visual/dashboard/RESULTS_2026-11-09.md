# Dashboard test, 9 November 2026 (evening)

Five models, same brief, one call each, no tools, no agents, no skill: brief + the model's
own quantitative report + the six 10-K extract files in a single prompt, one self-contained
HTML file as the answer. Not scored. The gap between models is read visually.

Folder layout
- brief_dashboard_v1.md: the frozen brief (v1; v1.1 adds the HTML self-check paragraph).
- inputs/: one quantitative report per model (see inputs/README.md for provenance) and the
  pointer to ../10k_fy2025/extracts/.
- outputs/<label>.html: the dashboard; <label>.prompt.txt: exact prompt sent;
  <label>.raw.txt: exact model answer; logs/: runner logs; screenshots/: headless Chrome
  captures at 1400x3200 used for the visual review.
- tools/run_dashboard.py: the runner (litellm for OpenAI and the Mistral platform,
  `claude -p --tools ""` for Claude under the subscription; `fix:` mode replays the
  model's own output plus the exact JavaScript error and asks for the corrected file).
- ai_capex_dashboard_v0.html: Claude's hand-made v0 on a three-line brief, kept as the
  counter-example (dataviz-heavy, little analysis, journalistic headings).

## What all five got right
- Investment register as soon as the brief gave the situation and the reader.
- The three divergent capex bases named (Amazon 131.8 vs 128.3 cash capex; Meta 69.7 vs
  72.2 incl. finance-lease principal; NVIDIA 3.2 vs 3.4).
- Apple treated as the control (no AI-infrastructure strategy disclosed).
- Initial FY2025 guidance, FY2025 actuals and 2026 indications kept apart; Meta compared
  only on the 72.2 basis.
- No invented figure found on the checks made; a fact-by-fact check needs the annotated
  report viewer.

## Lessons for the pipeline stage
- Output cap at 120,000 tokens for reasoning models.
- Run `node --check` on the inline script after generation; on error, one automatic
  correction turn with the exact error (Mistral fixed itself in one turn).
- The Period column of the quant report is not checked by the deterministic grader: both
  Mistral Large 4 reports at 100.0 of the 13/10 campaign say "NVIDIA FY2025 ended Jan 2026".
- One run per model only; variance unknown. Three runs per model before any claim on video.
